# Codex 작업 스킬

저장소 전용 스킬은 [work](../.agents/skills/work/SKILL.md)에 있다.
Codex에서 이 저장소 또는 해당 스킬이 포함된 작업 브랜치를 열어 사용한다.

```text
$work 164
$work 체크박스 연타 후 상태가 되돌아가는 문제
$work
```

이슈 생성·선택 → 기획 → 사용자 검수 → 구현 → 필요한 검증 → PR 생성 순서다.
기획 검수에서 이슈 초안(신규일 때), 완료 조건, 영향 범위, 구현·검증 계획을 확인한다.
승인 후에는 그 범위의 커밋·푸시·PR 생성까지 이어진다. PR 생성 뒤 머지는 별도 지시로 진행한다.
대상이나 제품 요구가 모호하면 필요한 정보를 묻고, 승인 범위가 달라지면 변경된 계획을 검수받는다.

절차와 필수 규칙의 원본은 [AGENTS.md](../AGENTS.md)다. Claude Code의 `/work`는
기존 명령으로 유지하며, 그 명령의 별도 푸시·머지 승인 단계를 Codex 스킬에 가져오지 않는다.
새 사용자 공용 사본을 설치할 필요가 없다. 스킬이 목록에 보이지 않으면 이 저장소에서 새
Codex 세션을 시작한다. main에서는 이 추가 PR이 머지된 뒤 사용할 수 있다.

## 검증 선택과 결과

2026-09-15 사용자 요청으로 생성하고 저장소 전용 위치를 확정했다.
이번 변경은 스킬·설명·작업 규칙 문서만 다룬다.

- skill-creator의 `quick_validate.py`: 필수 frontmatter·이름·미완성 자리표시자 검사 통과.
- `agents/openai.yaml` 파싱과 설명 길이 검사 통과.
- `git diff --check` 및 문서 참조 경로 확인 통과.
- 기존/신규 이슈, 테스트 생략, 검사 실패, 승인 후 재개 흐름을 지침과 대조했다.
  실제 작업을 실행한 E2E 검증은 아니며 외부 이슈·PR을 만드는 자동 실행 테스트는 추가하지 않았다.

앱 코드·빌드 설정·실행 스크립트가 바뀌지 않아 lint/build·unit·E2E·성능 측정은 선택하지 않았다.
검사에 사용하는 skill-creator 도구는 로컬 Codex 제공 도구이며 이 저장소의 실행 의존성이 아니다.
