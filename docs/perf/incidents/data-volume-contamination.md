# 데이터 볼륨이 코드 회귀처럼 보인 사건

2026-07-27 성능용 데이터가 대량 시딩되면서 다음 날 로컬 Lighthouse에 회귀 델타가
한꺼번에 생겼다. 경량 회차는 태스크 약 120건·공고 0건, 대량 회차는 태스크 약
9,100건·공고 200건이었다. 데이터 의존 페이지(`/jobs`·`/history`·`/monthly`)만 크게
느려지고 데이터 무관 페이지는 유지돼 원인이 코드가 아니라 데이터셋임을 확인했다.

두 회차는 코드도 완전히 같지 않아 정량적인 “규모 비용” 기준선으로 사용하지 않는다.
당시 표와 사후 해석은 `../archive/local-history-2026-07-21--2026-08-20.md`에 보관한다.

이 사건 이후 적용한 규칙:

- perf와 E2E 계정 분리
- 매 로컬 측정에 데이터 볼륨 기록
- 한쪽 볼륨이 없거나 임계값을 넘게 달라지면 델타를 만들지 않음
- 측정 자체가 데이터를 쓰는 배포 API 경로 금지

비교 조건을 기록하지 않은 숫자는 코드 전후 델타가 아니라 관찰 메모로만 취급한다.
