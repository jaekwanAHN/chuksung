않되 활성 원장과 분리해, legacy 조건을 현재 성능으로 읽지 않게 한다.

| 로컬 2026-08-20 | **알려진 오측정** | 8개 대시보드 경로가 로그인 화면으로 수렴 (#145) |

| 배포 2026-08-20 | legacy 자동 측정 | E2E 계정·배포 SHA 미기록·혼합 진입 엣지 |

있다.
